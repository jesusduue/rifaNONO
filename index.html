💡 Las tasas se usan para convertir a USD al momento de registrar cada pago, y cada pago guarda la tasa usada (transparencia). Ajústalas cuando cambien.

Cómo funciona el control
  • ⏳ Reservado la persona eligió el número, sin abonos aún.
  • 🟠 Abonado pagó una parte del valor del número.
  • ✅ Pagado completó el valor del número.
  • Cada pago se reparte en orden entre los números seleccionados hasta completarlos.
  • Los estados se calculan siempre desde los pagos registrados: si eliminas o editas un pago, los números se recalculan solos.
Respaldo y transparencia

Los datos se guardan solo en este navegador. Exporta respaldos con frecuencia, o para pasar el control a otro celular/computadora (importa el archivo allá).
